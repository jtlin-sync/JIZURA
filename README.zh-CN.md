## 1. 项目简介

输入歌词后，JIZURA 会组合文字 PV，也就是动态歌词视频中常见的表现手法，自动生成各个镜头，并导出 MP4。它将版式、动作、装饰、转场和后期效果拆分为 **860 个部件**，提供 **27 套风格**。改变随机种子，就能获得另一套编排。

项目还附带两种 After Effects 面板，包括脚本版和可直接使用浏览器版界面的 CEP 版。[项目仓库][repo]

主要功能包括以下内容。

- 浏览器版即开即用。歌词、音乐及导出过程均在浏览器本地处理，输入内容无需上传服务器。外部字体按需从 Google Fonts 加载，只加载当前编排实际使用的字体。
- 点击“一键生成”，或按 `R`，即可重新随机生成风格、氛围、动作、配色和编排。
- 支持 `16:9`、`9:16`、`4:3`、`3:4`、`1:1`、`4:5`、`21:9` 画面比例，分辨率从 720p 到 4K，帧率可选 24、30、60 fps。
- 导入音乐后自动检测节拍，并将镜头切换对齐节拍，也可通过轻点同步手动校时。
- 可导出带音乐的 MP4、PNG 序列、透明 PNG，以及绿幕、黑底合成素材。
- 可导出编排数据 JSON，在 After Effects 中生成可编辑合成。

## 3. 运行环境

- **MP4 导出**需要支持 WebCodecs 的浏览器。原说明推荐 Chrome 或 Edge。Safari 16.4 及以上、Firefox 130 及以上也支持 WebCodecs，但能否导出 H.264 取决于浏览器和操作系统。其他环境仍可使用预览和 PNG 序列导出。
- **手机使用**方面，iPhone 可使用 iOS 16.4 及以上的 Safari，Android 可使用 Chrome。原说明建议在电脑上进行长歌曲、高分辨率导出。
- **字体加载**采用 Google Fonts 按需加载。离线时使用电脑已安装的字体替代。

以上环境要求按源 README 翻译。[日文主说明][readme-ja]

## 4. 快速开始

1. 打开简体中文版，在左侧歌词区粘贴歌词，每行一句。
2. 按需导入音乐。应用会检测 BPM 和节拍，也可点击“轻点同步”，在播放过程中按空格键标记每行的开始时间。
3. 点击“一键生成”，或按 `R`，尝试一套编排。通过“上一个”“下一个”浏览方案，也可用“只换这一项”单独调整某个部分。
4. 选择画面比例、分辨率和帧率，导出 MP4。详细模式可进一步控制表现手法、PNG 序列、透明素材和合成背景。

本节根据英文 README 的快速开始整理。[英文说明][readme-en]

## 5. 随机生成与手机模式

### 5.1 简易模式与一键生成

通过右上角的“简易 / 详细”切换界面。首次打开使用简易模式，手机首次打开使用手机模式。

每次点击“一键生成”，或按 `R`，应用都会重新随机决定以下内容，并从头播放。

- **风格**会避开刚刚使用的上一套风格。
- **氛围**包括故障、柔和、波普、图形、杂志、感性和不拘一格。启用恐怖特效后，还会加入恐怖氛围。不同氛围会影响动作强度、故障程度，以及版式、入场和退场手法。
- **字体**包括标题和明朝体，也就是日文字体中的衬线体类别。
- **配色**有时也会重新随机强调色与色差 A/B。
- **镜头编排**由随机种子控制。

“上一个 / 下一个”可在已生成方案之间切换，回到喜欢的方案后再导出。“只换这一项”可分别重抽风格、配色、氛围或编排。

随机生成会保留歌词、音乐、时间设置、导出设置和已锁定的行。

### 5.2 随机抽选的部件范围

通过一键生成按钮下方的复选框，或详细模式“手法”标签页顶部的复选框，控制一键生成、随机编排和逐行重抽使用的部件范围。

| 选项 | 默认状态 | 作用 |
| --- | --- | --- |
| 使用新增特效 | 关闭 | 关闭时使用首个公开版的 356 个部件和 12 套风格。开启后将后续新增的 351 个部件、12 套风格和 6 款字体加入候选 |
| 使用和风特效 | 开启 | 控制提灯、明信片、障子、折扇、家纹、青海波、樱花花瓣等图形，以及“樱花”“墨与朱”等风格。此筛选在新增部件筛选之后生效 |
| 使用文字排版部件 | 开启 | 加入 50 个以线条、数字和文字编排为核心的部件，如大字夹排、裁切大字、十字排版、注音、线框排版、字号递增、宽度对齐、文字剖分、行内强调、重新打字、括号开合、页眉与页码 |
| 使用动态文字部件 | 开启 | 加入 51 个逐词运动的部件，如堆叠、直角转向、位置交换、潜入字形、流动后对齐、逐词切镜、齿轮、正面碰撞、逐词砸入、铰链翻落、逐词节拍、跟读镜头、碎切。存在音乐节拍时，词语切换会对齐节拍 |
| 也使用恐怖特效 | 关闭 | 加入 52 个诡异氛围部件及“废墟”“深夜录像”“诅咒信件”3 套配色风格 |

恐怖部件包括手电筒、门缝、墙面涂鸦、监控屏、通灵板、寻人启事、单字异常、涂黑文档、雪花电视、灵异照片、异常影子、眨眼间逼近、突然弹出、镜像文字、拖拽下沉、残留单字、抽搐、凝视文字、注视的眼睛、魔法阵、裂纹、黑暗走廊、扩散污渍、惊恐手持、潜意识闪帧、掠过的影子、雪花切镜和眨眼等。原文说明这些效果未加入血液、伤口等血腥表现。

启用恐怖特效后，一键生成约有一半概率选择恐怖氛围。自动生成时，恐怖部件仅在该氛围中使用。

文字排版、动态文字和恐怖这三组部件分别独立于“使用新增特效”开关，即使关闭新增特效，也可启用这三组部件。

手动指定某行的版式等部件，或手动选择风格时，可以直接选择相关项目。“手法”与风格列表会标出“新增”“和”等标记，当前设置下不会被随机选中的项目以较淡的颜色显示。日文界面中，文字排版、动态文字、恐怖部件分别标为“文”“キ”“ホ”，简体中文界面对应“文”“动”“恐”。

### 5.3 主题

一键生成按钮旁的“主题”，在简易模式中位于按钮下方，可选文字 PV、动态文字、和风、恐怖、流行和抒情。

选择主题后，应用会在该方向内随机生成，并自动开启所需部件组，包括文字排版、动态文字、和风及新增部件、恐怖等。“不指定主题”沿用当前的自由随机方式。

### 5.4 手机模式

在窄屏或触屏设备上，右上角显示“手机 / 简易 / 详细”三种模式，首次打开进入手机模式。

- 一键随机按钮固定在顶部，滚动时也可随时操作。
- 预览固定在上方，滚动时仍可查看播放画面。
- 行列表默认每行只显示歌词。点击某行，展开该行的骰子、锁定和镜头数量等设置。
- 点击分组标题，可折叠或展开歌词、行列表和设置。
- 保存、打开和初始化等操作集中在“菜单”内，按钮按触屏操作设计。
- 默认导出分辨率为 720p。手机模式导出上限为 1080p，选择更高分辨率时会按 1080p 导出。更高分辨率可在详细模式中使用。
- 导出期间会尝试保持屏幕常亮，切换到其他应用所花的时间会从失败判断中排除。
- 导出后，在支持的浏览器中可使用“分享并保存”，将视频保存到照片等应用。

## 6. 浏览器版详细用法

### 6.1 歌词语法

每行代表一个短句。可使用以下标记控制切镜、强调、注释和时间。

| 写法 | 含义 |
| --- | --- |
| `我还记得/黎明的颜色` | 用 `/` 指定镜头切分位置 |
| `*透明*` | 强调标记，更容易选用大字和冲击力较强的效果 |
| `这一句歌词!` | 行末 `!` 加入闪光和震动 |
| `歌词\|注释` | 为注释版式提供小字，用半角竖线分隔歌词与注释 |
| `[01:23.45]歌词` | 使用 LRC 时间戳 |
| `[间奏 8]` | 插入 8 秒间奏，显示背景、装饰和画面效果 |
| `# 注释内容` | 以 `#` 开头的注释行会被忽略，此项补自英文 README |

间奏也支持 `[間奏]`、`[interlude]`、`[간주]`。省略秒数时默认为 4 秒，可通过轻点同步或标记点调整长度。间奏达到 6 秒及以上时，会以小字显示歌名和艺人。

歌词与注释的实际输入示例如下。

```text
歌词|注释
```

歌词区右上角的“读取 LRC”可导入 `.lrc` 文件，替换当前歌词。可通过“撤销”恢复。LRC 中没有时间戳的行会保留书写顺序，并安排在前后时间戳之间。

### 6.2 音乐与时间同步

导入音乐后，应用会自动检测 BPM 和节拍，将镜头边界吸附到节拍。已导入的音乐会保存在当前浏览器中，再次打开页面时自动载入。

使用轻点同步时，可按以下步骤操作。

1. 点击“轻点同步”，开始播放音乐。
2. 每行歌词开始时，按 `Space` 空格键。
3. 标记错误时，按 `Backspace` 或点击“退回一步”。
4. 点击行列表中的 `◎`，可从该行重新同步，前面各行的时间会被保留。
5. 一行包含多个镜头时，在镜头切换瞬间按 `Tab`，标记该行后续镜头的开始时间。

同步过程中，可将“速度”设为 `0.75×` 或 `0.5×`。保存的仍是音乐原始时间位置。启用“倒数”后，音乐在 `3、2、1` 倒数结束后开始。

也可直接修改行列表中的秒数。若输入值会使前后行的时间顺序倒置，应用会自动调整到保持顺序的位置。

在详细模式中，每行下方会显示第二个及后续镜头的开始时间。输入数值可固定时间，清空则恢复自动。当前播放镜头会以边框标示。

### 6.3 时间轴

- 左右拖动时间轴上方的行分隔标记，修改该行开始时间。
- 默认吸附节拍，按住 `Shift` 可自由拖动。
- 使用 `+`、`−` 或鼠标滚轮缩放。
- 使用 `Shift + 滚轮` 左右平移。
- 点击“全曲”恢复全曲视图。
- 歌词和时间的修改可通过“撤销”或 `Ctrl + Z` 取消。

### 6.4 逐行与逐镜头编辑

- 点击 `✎`，或双击歌词，即可原地编辑该行，并继续使用歌词语法。
- 通过镜头数量设置，选择自动，或将一行拆分为 `1～6` 个镜头。
- 点击某行的骰子，只重新抽选该行。
- 锁定某行后，其他行的骰子、随机编排和一键生成会保留该行的版式、动作、装饰、配色和切镜安排。
- 详细模式可直接指定版式。
- 点击“随机编排”，可重新抽选整体编排。

详细模式中，点击预览下方的镜头信息，例如版式、入场、保持、退场、装饰、文字加工、背景、镜头运动或转场，可展开列表，仅替换当前镜头的对应部件。选择“自动”恢复自动抽选。

行列表也会显示各镜头的版式选择框。“随机编排这个镜头”或“这个镜头一键随机”可仅重抽当前镜头，其他镜头保留已抽选的结果。

### 6.5 锁定与循环

详细模式提供以下锁定功能。

- “手法”标签页各分类旁的锁，可保留该分类的启用和关闭选择。
- “特效”标签页滑块、闪光、抽帧旁的锁，可保留对应数值。
- 锁定状态会写入项目文件，并在一键生成后继续生效。

播放按钮旁的“循环”按以下顺序切换。

`全曲 → 当前行 → 当前镜头 → 关闭`

循环当前行或镜头时，时间轴会标出对应范围。

### 6.6 风格与配色

共有 27 套结合配色、字体和质感的风格，包括樱花、深海、日落渐变、森林笔记、蒸汽波、新闻纸、80 年代合成器、牛皮纸、糖果、酸性、墨与朱、金色之夜，以及恐怖主题的废墟、深夜录像、诅咒信件等。同一视频中，不同镜头也会切换背景色。

字体从 Google Fonts 的 18 个字体家族中选取，包括 Reggae One、Rampart One、Potta One、Kiwi Maru、Klee One、Shippori Mincho B1。应用只按需加载当前编排使用的字体。

可通过输入电脑已安装字体的名称，或导入 `.ttf`、`.otf` 文件，更换字体。

在“详细 → 风格 → 强调色与色差”区域，可随机生成配色或直接选色。

- 随机配色会同时选择强调色和色差 A/B。
- 略低于一半的结果来自预先调配的组合，例如互补色组合，其余结果每次根据色相环生成。
- 应用根据背景亮度自动修正明度，保持可读性。强调色与背景的对比度至少为 3。
- 取消自定义颜色覆盖后，恢复风格原本的颜色。

### 6.7 特效与手法

在“特效”标签页，可调整动作强度、故障、色差、装饰数量、切镜密度、质感和抽帧。

“隐藏装饰数字”和“隐藏装饰时间”可隐藏版式、装饰或 HUD 附加的 `No.01`、`00:12.34` 等文字，歌词自身包含的数字和时间会被保留。

“手法”标签页可逐项启用或关闭 10 类部件，包括版式、入场、保持、退场、装饰、文字加工、背景、镜头运动、画面效果和镜头间转场。每类支持折叠、全部开启、全部关闭、反选和按名称筛选，并与新增、和风等部件范围开关共同生效。

### 6.8 统一感与文字排列

“统一感”位于“特效”标签页，也可在简易模式中勾选。启用后，会按文字 PV 的常用编排方法组织画面。

- 按空行划分段落，在同一段内统一版式、动作、镜头运动和装饰。
- 再次出现的歌词，例如副歌，会沿用第一次的呈现方式。
- 交替安排运动方向，例如从左到右、从上到下，把强烈动作集中在重点行。
- 将行末带 `!` 的行作为强调点，以单个镜头配合大字、闪光、缩放和震动。若没有 `!`，会使用重复段落的首行。
- 同一行的相邻镜头可使用字形变换，相同文字移动到新位置，其他文字溶解变化。
- 有时通过 Noto Sans JP 或 Noto Serif JP 的可变字体，呈现由细到粗的字重变化。

“文字排列”会收紧假名字距，将日文助词如“は、が、を、に”缩小，放大行首字母或汉字，略微放大拉丁字母，并为其与日文之间加入少量间距。

文字会比人声提前 0.2 秒出现，并限制效果叠加，每个镜头最多一个装饰和一个画面效果。

这两项均可按需启用。导入 AE 时会带入选中的版式、动作和时间，字距、字号、字重及字形变换会以近似方式实现。

### 6.9 留出画面中央

“留出画面中央（放角色用）”位于导出设置中，适合后续在中央叠加角色等素材。

- 每行歌词拆成前后两部分，例如“花儿 / 开了”。
- 横屏放在左右两侧，侧带各占画面宽度约 36%，`21:9` 时约 30%。
- 竖屏默认放在上下两侧，侧带各占高度约 33%。也可选择左右分布，各占宽度约 34%。
- 两侧共用同一场景的版式、动作、装饰和镜头运动，后半部分稍晚出现。
- 只有一个词的短行，会在两侧显示相同词语。
- 背景和画面效果仍覆盖整个画面，同时排除将歌词大字铺作背景的“大字单字”背景。
- 预览用虚线标出留空区域，导出画面仅保留实际内容。
- AE 脚本面板的“从歌词生成”、CEP 面板及 AE JSON 都支持相同布局。

### 6.10 界面、预览与首次引导

屏幕足够宽高时，预览和时间轴固定显示，左侧歌词及行列表、右侧设置分别在各自列内滚动。播放时行列表自动跟随当前行，手动滚动后会暂时停止跟随。窄屏使用整页滚动。

界面语言可选日文、英文、印尼文、越南文、繁体中文、简体中文和韩文。各语言界面可打开同一项目文件。原日文 README 将非日文界面的部件名称描述为英文，仓库的简体中文翻译文件还提供了中文部件名称。[日文主说明][readme-ja] · [简体中文界面译文][ui-zh]

播放按钮旁的音量滑块控制预览音量，点击“音量”可静音或取消静音，设置会记在浏览器中。MP4 按原始音量导出。

首次进入简易模式时，引导会依次介绍歌词、音乐、一键生成、播放、逐行修正和导出。点击顶部 `?` 可再次查看，用 `←`、`→` 切换步骤，按 `Esc` 退出。

### 6.11 保存、打开、清除与初始化

通过“保存”和“打开”管理 `.jizura.json` 项目文件。“导出到 AE”生成的是供 AE 面板导入的编排 JSON。本项项目保存说明补自英文 README。[英文说明][readme-en]

“清除歌词”位于歌词区右上角，会清除歌词、各行时间、逐行设置及导出范围，可通过“撤销”或 `Ctrl + Z` 恢复。

顶部“初始化”在确认后清除歌词、音乐，包括浏览器中保存的音乐、设置、方案历史和撤销历史，并回到初始状态。**初始化操作无法撤销。**界面模式、预览音量和界面语言会继续保留。

## 7. 导出与合成

### 7.1 导出格式与范围

| 格式 | 用途 |
| --- | --- |
| MP4 | 导出视频，可包含音乐。Chrome / Edge 使用 H.264 |
| PNG 序列 ZIP | 按帧导出图片序列 |
| 透明 PNG ZIP | 导出透明背景素材，供 AE 等软件合成 |
| 透明 PNG 前景／后景 ZIP | 每帧分别导出前景与后景两个透明图层 |
| 歌词 LRC | 为各行歌词附加开始时间，保存为 `.lrc` 文件 |
| AE JSON | 保存时间、版式、特效和配色等编排数据，用于 AE 面板生成可编辑合成 |

简易模式也可导出 PNG 序列和透明 PNG。

在“导出范围”中选择首行和末行，或点击行列表的 `⇥`，可只导出指定行。按 `Shift + 点击` 可扩大范围。文件名会带有 `_L03-05` 等行号标记。

导出 LRC 时，若已选择导出范围，仅导出这些行，时间从导出视频的开头重新计算。

### 7.2 画面比例、分辨率与帧率

画面比例可选 `16:9`、`9:16`、`4:3`、`3:4`、`1:1`、`4:5`、`21:9`，分辨率从 720p 到 4K，帧率可选 24、30、60 fps。

1. 在“导出”标签页选择画面比例、分辨率和 fps。简易模式使用右侧的导出区域。
2. 点击导出 MP4。输出帧数按所选 fps 计算，例如 6 秒视频在 24 fps 时为 144 帧，在 60 fps 时为 360 帧。
3. 在“特效 → 抽帧”中选择动作更新方式。此项独立于输出帧率。

| 抽帧模式 | 动作表现 |
| --- | --- |
| 两帧一拍，12 张/秒 | 默认模式，呈现文字 PV 常见的略带顿挫感的动作。各输出帧率下保持相同观感 |
| 三帧一拍，8 张/秒 | 更接近手绘动画的停顿感 |
| 全帧 | 每个输出帧都更新动作。60 fps 配合全帧时最平滑，适合镜头运动和流动条带 |

故障、闪烁等随机切换以 24 fps 为时间基准，切换输出帧率时保持相同速度。

原说明给出的参考是，YouTube 或 MV 可使用 24 fps 或 30 fps，需要平滑动作的社交平台竖屏视频可使用 30～60 fps 配合全帧。60 fps、4K 导出所需时间更长。

AE 面板也可通过 fps 选项设置 24、30、60 fps。由 JSON 生成时，采用浏览器版所选帧率。

### 7.3 长视频与音频

应用以逐步写入的方式生成视频，降低长歌曲以及 1080p、1440p 导出时的集中内存占用。GPU 编码失败后，会自动切换软件编码重新导出。

Chrome / Edge 提供“大型视频用（直接保存为文件）”，可先选择目标文件，再直接向该文件写入，适合长歌曲和高分辨率导出。

若浏览器无法输出 AAC 音频，例如只能使用 Opus，或无法导出音频，应用会额外保存一份与视频等长的 WAV 音频，以应对 iPhone、QuickTime 等环境中的音频兼容问题。

### 7.4 绿幕与黑底合成素材

在实拍或插画视频上叠加歌词时，可在导出设置的“背景”中选择以下模式。

| 模式 | 画面 |
| --- | --- |
| 普通 | 使用风格原有的配色和背景，默认选项 |
| 绿幕 | `#00FF00` 背景上的白色文字与效果 |
| 黑底 | `#000000` 背景上的白色文字与效果 |

所选背景立即反映在预览中，右上角会显示当前模式。MP4 和 PNG 序列使用所选合成背景，透明 PNG 保留透明底。文件名末尾会添加 `_greenback` 或 `_blackback`。

合成时可采用以下方式。

- **绿幕素材**可使用剪辑软件的色度抠像工具，如 Premiere Pro 的 Ultra Key、DaVinci Resolve 的 3D Keyer、AE 的 Keylight 去除绿色。
- **黑底素材**可用“滤色 Screen”或“相加 Add”混合模式叠加，也可用亮度抠像去除黑色。
- **透明 PNG**直接提供透明背景上的白色素材。

合成模式中的文字、装饰和效果统一为白色至灰色。风格配色、背景花纹、纸张质感、颗粒和暗角会被排除，镜头编排、动作及部件组合沿用原方案。

色差重影和光晕用灰色绘制，抠像后呈现半透明效果。绿幕模式的目标观感与黑底素材使用滤色合成后的效果一致。

闪光、反相、频闪等全屏效果会作为白光保留。可在“特效”中关闭闪光、减弱故障，或在“手法 → 画面效果”中单独关闭相关部件。

AE 面板也有相同背景设置，导出到 AE 的 JSON 会记录该设置。

### 7.5 透明 PNG 前景与后景

选择“透明 PNG 前景／后景（ZIP）”，每帧会导出两张透明 PNG，分置于以下目录。

| 目录 | 内容 |
| --- | --- |
| `back/` | 后景，包括背景图形和歌词后方的装饰 |
| `front/` | 前景，包括歌词、周围装饰与边框、色差重影和 HUD |

全屏效果，例如闪光和分屏，会同时作用于两层。将 `front` 叠在 `back` 上，可还原通常的画面组合，其中排除背景底色、纸张质感、发光和扫描线。

透明 PNG 导出时，反相、闪光、频闪、色相偏移、分屏、上下滑动、CRT 关机和黑帧等效果只作用于文字与装饰区域。黑帧、白帧对应的帧会导出为空白透明帧。

## 8. 歌词语言与字体

### 8.1 语言识别

原风格基于日文字体设计。繁体中文、简体中文和韩文歌词可能因为缺字而混用其他字体，可通过歌词区下方的“歌词语言”设置整行采用对应语言的字体。

- **自动识别**为默认选项。含假名时判为日文，含韩文字母时判为韩文，仅有汉字时会根据“們 / 们”“說 / 说”等繁简特征判断。识别结果显示在设置旁。
- 可手动选择日本語、繁體中文、简体中文、한국어或 English。
- 几乎全部由拉丁字母组成的歌词，包括英文和罗马字，会判为 English。
- English 模式按两三个词组成的短语划分镜头，手动输入的 `/` 优先作为切分位置。
- 切换语言后，各字体会替换为该语言中风格相近的字体，并从 Google Fonts 自动加载。

### 8.2 字体对应关系

| 日文字体 | 繁体中文 | 简体中文 | 韩文 |
| --- | --- | --- | --- |
| Noto Sans JP、Zen Kaku Gothic New、IBM Plex Sans JP | Noto Sans TC | Noto Sans SC | Noto Sans KR、IBM Plex Sans KR |
| Noto Serif JP、Zen Old Mincho、Kaisei Tokumin、Shippori Mincho B1 | Noto Serif TC | Noto Serif SC | Noto Serif KR |
| Dela Gothic One | WDXL Lubrifont TC | ZCOOL QingKe HuangYou | Black Han Sans |
| M PLUS Rounded 1c | Chiron GoRound TC | ZCOOL KuaiLe | Jua |
| Mochiy Pop One、Kiwi Maru | Huninn | ZCOOL KuaiLe | Do Hyeon、Gowun Dodum |
| Klee One、Yuji Syuku | LXGW WenKai TC | ZCOOL XiaoWei、Ma Shan Zheng | Gowun Batang、Nanum Brush Script |
| Reggae One、Rampart One、Potta One | LXGW Marker Gothic | ZCOOL QingKe HuangYou、Ma Shan Zheng | Black Han Sans、Nanum Brush Script |

DotGothic16 和用于小型英数字的 IBM Plex Mono 继续沿用原字体，仅缺失字符由各语言的无衬线字体补齐。

中文、韩文歌词中，由假名生成的罗马字小注释会改用行号、注释、字符编码等内容。

字体选择框会显示实际使用的字体，例如 `Noto Sans JP Black → Noto Sans TC 900`。

### 8.3 AE 中的字体

AE 面板提供同样的歌词语言设置，AE JSON 也会携带语言信息。

已安装上述字体时，AE 使用相应字体。否则回退到操作系统字体，例如繁体中文的蘋方-繁、微軟正黑體，简体中文的苹方-简、微软雅黑，以及韩文的 Apple SD Gothic Neo、Malgun Gothic。

## 10. After Effects 面板

### 10.1 两种面板

两种面板使用同一套生成引擎。

| 类型 | 功能 |
| --- | --- |
| ScriptUI 脚本版 `JIZURA_AE.jsx` | AE 原生脚本面板，可从歌词生成，也可导入浏览器版 JSON |
| CEP 版 `JIZURA_CEP.zip` | 在 AE 中使用浏览器版界面和预览，点击“在 AE 中生成合成”即可生成当前编排 |

英文版对应 `JIZURA_AE_en.jsx` 和 `JIZURA_CEP_en.zip`。日文和英文面板使用相同 AE JSON 格式。英文 CEP 面板使用独立扩展 ID，可与日文 CEP 面板并存。[英文说明][readme-en]

### 10.2 安装 ScriptUI 脚本版

1. 将 `JIZURA_AE.jsx` 放入对应目录后，重启 AE。

   - Windows 使用 `C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Scripts\ScriptUI Panels\`。
   - macOS 使用 `/Applications/Adobe After Effects <版本>/Scripts/ScriptUI Panels/`。

2. 通过“窗口 → JIZURA_AE.jsx”打开面板，可将其停靠到工作区。
3. 临时试用也可选择“文件 → 脚本 → 运行脚本文件”，此时以浮动窗口打开。

英文版按同样方法安装对应的 `_en.jsx` 文件。

### 10.3 从歌词生成

在“从歌词”页面，也就是日文的“歌詞から”，设置歌词、风格、尺寸和特效，然后点击“生成合成”，日文为“コンポを生成する”。

时间设置有三种来源。

- 根据文字数和 BPM 自动计算。
- 使用所选图层的标记点。
- 使用合成标记点。

原说明建议先选择音乐图层，边播放边按数字小键盘的 `*`，在每行开始处打标记，然后选择“使用所选图层标记作为行首”生成合成。

“随机生成”每次会重新决定风格、氛围、效果强度、两帧一拍、闪光、HUD、种子和配色，将结果同步到面板并创建新合成。选中满意结果后，可调整数值，再点击“生成合成”重建。

在“特效”区域选择氛围后，面板会从符合该氛围的版式、入场和退场手法中抽选。相同种子会产生相同抽选结果。

### 10.4 配色、部件与尺寸

通过“随机配色”重新选择强调色和色差 A/B，也可直接输入 `#RRGGBB`。勾选覆盖风格颜色后，配色应用于生成合成的全部场景，明度根据背景自动修正。

面板提供与浏览器版相同的新增、和风、文字排版、动态文字、恐怖部件开关，以及普通、绿幕和黑底背景。可选择全部 27 套风格，列表中的新增、和风、恐怖标记用于区分。启用恐怖效果后，氛围选项也会加入恐怖。

支持的预设尺寸如下，也可使用当前活动合成的尺寸。

| 尺寸 | 比例 |
| --- | --- |
| 1920×1080 | 16:9 |
| 1080×1920 | 9:16 |
| 1080×1080 | 1:1 |
| 3840×2160 | 16:9，4K |
| 1280×720 | 16:9，720p |
| 1440×1080 | 4:3 |
| 1080×1440 | 3:4 |

### 10.5 支持的效果与 JSON 导入

面板支持浏览器版全部 860 个部件，通过 AE 文字图层、形状图层、蒙版、效果和表达式构建。v0.9.0 已将文字排版、动态文字和恐怖三组共 153 个部件加入 AE。各部件中的歌词均保留为可编辑文字图层。

- 逐词动态部件使用逐词文字图层，或单个文字图层的逐字动画器实现。
- 浏览器中跟随节拍的部分，在 AE 中以镜头时长均分的方式安排动作。
- 3D 旋转、翻纸以及像素排序、抖色等逐像素处理，通过 AE 标准效果和二维变形近似实现。
- JSON 含有面板尚未识别的部件时，会以最接近的部件替代，并在面板底部状态中显示“存在替换”，日文为“置換あり”。

在“从 JSON”页面，也就是“JSONから”，导入浏览器版“导出到 AE”生成的 JSON，即可按浏览器中的时间、版式、效果和配色生成合成。

安装有 Noto Sans JP、Noto Serif JP、Dela Gothic One 等字体时，面板会自动使用，自动选字体适用于 AE 2024 及以上。缺少字体时，使用“字体”标签页指定字体，默认是 Yu Gothic 和 Yu Mincho，也就是游ゴシック、游明朝。

### 10.6 轻量模式、长歌曲与诊断

“轻量”模式会省略色差复制图层、纸张质感、发光、颗粒以及需要复制画面的全屏效果，图层数量约减少 40%，以改善 AE 播放表现。

脚本版和 CEP 版均会分批创建长歌曲合成，面板显示百分比和镜头数量。点击“停止”，会将已生成的镜头整理为合成。

由于撤销记录按生成步骤拆分，原说明建议重建时在项目面板中删除相应合成及 `cuts` 文件夹。

“从 JSON”页面的“诊断报告”会让 AE 计算上一次生成合成的表达式，并将错误和替换记录保存为 `JIZURA_report.txt`。反馈异常时，可附上该文件。

### 10.7 安装与使用 CEP 版

1. 下载并解压 `JIZURA_CEP.zip`。
2. Windows 运行 `install_win.bat`，macOS 运行 `install_mac.command`。安装程序会复制到用户 CEP 扩展目录，并启用加载未签名面板的设置。
3. 重启 After Effects 2022 或更高版本，通过“窗口 → 扩展 → JIZURA 字面”打开。

CEP 面板中的歌词、风格和特效设置方式与浏览器版相同。

- 点击“在 AE 中生成合成”，日文为“AEでコンポを生成”，创建当前编排。
- 在“导出范围”选择行后，仅生成该范围的合成，音乐图层会同步对齐。导出到 AE 的 JSON 使用同一范围，便于将长歌曲分段生成。
- 先在 AE 中选择音乐图层，再点击“AE 中选中的音乐”，日文为“AEで選択中の曲”，可分析音乐并对齐节拍，同时将该音乐加入合成。
- “使用 AE 标记作为行首”，日文为“AEのマーカーを行頭に”，使用所选图层的标记，若未选中图层则使用合成标记。
- 可直接在面板中导出 MP4 和 PNG 序列，并通过对话框选择保存位置。
- 详细安装方法及用于分发的已签名 `.zxp` 构建方法，见压缩包中的 `README_CEP.md`。

### 10.8 生成的合成与图层

- 每个镜头生成一个预合成，存放在 `JIZURA <曲名> cuts` 文件夹。
- 部分镜头内部还包含 `JZ … art` 等预合成，以及 `… ghost` 色差副本。ghost 副本会排除纸张、面板等背景物件。
- 生成结束后清理未使用的隐藏图层，保留用于轨道遮罩的隐藏图层。
- 文字通过文字动画器和表达式选择器运动，修改文字后仍可沿用动作。
- 色差由具有时间偏移的镜头副本形成，并通过“色调 Tint”效果着色。
- 顶层 `JZ FX` 调整图层集中包含两帧一拍的“时间海报化 Posterize Time”、震动用的“变换 Transform”、切片故障用的“波形变形 Wave Warp”，以及缩放模糊、反相、发光和噪点。
- 另会生成 `JZ Flash`、`JZ Vignette` 及显示时间码、行计数的 HUD。
- 绿幕或黑底模式以 `JZ Key Mono` 单色化调整图层替代 `JZ Vignette`。绿幕还会生成使用滤色混合模式的 `JZ Key Green`。

### 10.9 原说明中的验证情况与注意事项

- 脚本版以 AE 2020 及以上为目标，使用 JavaScript 表达式引擎，即新建项目的默认引擎。CEP 版安装说明要求 AE 2022 及以上。
- 原作者使用模拟 AE 对象模型的环境进行自动验证。原文的测试段落列出 707 个部件在不同字数、画面比例下的构建，以及全部风格、多组种子的随机生成和浏览器版观感对比。
- **原 README 明确说明尚未在实际 AE 环境运行验证。**效果设置等异常会在生成后列出，其余部分继续生成。此处描述的是原作者声明的验证范围。
- 原文功能统计为 860 个部件，测试段落仍写 707 个，本译文保留这两处原始统计。
- 复杂镜头包含较多图层和表达式，长歌曲的生成和预览可能较慢。原说明建议将预览分辨率调为 `1/2～1/4`。

## 11. 开发构建与发布

### 11.1 构建要求与命令

构建需要 Python 3 和 Node.js，常规构建直接使用这两个运行环境。

在仓库根目录执行以下命令。

```sh
# 构建浏览器版
python3 build.py

# 修改 src/ 后更新 AE 面板使用的风格和部件数据
node tools/export_ae_data.js

# 构建日文 AE 脚本面板
python3 build_ae.py

# 构建日文 CEP 面板
python3 build_cep.py
```

对应关系如下。

| 命令 | 输入与输出 |
| --- | --- |
| `python3 build.py` | 由 `src/`、`app/`、`vendor/` 构建主页面与各语言独立页面 |
| `node tools/export_ae_data.js` | 更新 `ae/data.json` 中供 AE 使用的风格与部件数据 |
| `python3 build_ae.py` | 将 `ae/` 主体及 `ae/p_*.jsx` 部件包构建为 `JIZURA_AE.jsx` |
| `python3 build_cep.py` | 由浏览器页面、`ae/`、`cep/` 构建 `build/com.852wa.jizura/` 和 `build/JIZURA_CEP.zip`，发布时将 ZIP 复制到仓库根目录 |

版本写在仓库根目录的 `VERSION` 中，构建时会注入网页、AE 脚本面板和 CEP 面板。修改版本后，也应更新 `CHANGELOG.md`。

将 README 转成折叠标题结构可使用以下命令，新增标题按 `<details>` 结构编写。

```sh
python3 tools/fold_readme.py README.md
```

添加表现部件请参考开发指南，测试工具位于 `dev/`。[表现部件包开发指南][packs]

### 11.2 AE 模拟环境测试

先安装开发测试依赖，再从仓库根目录运行测试。

```sh
cd dev
npm install
cd ..
node dev/ae_test.js
```

测试通过模拟 AE 对象模型构建各套风格。实际 AE 中的动作与导出行为仍需在 AE 内核验。

### 11.3 多语言构建补充

英文 README 说明，`python3 build.py` 会生成根目录页面，以及 `en/`、`zh-hant/`、`zh-hans/`、`ko/`、`id/`、`vi/` 各语言版本。翻译源文件位于 `app/english.py` 和 `app/i18n_*.py`。[英文说明][readme-en]

英文 AE 面板使用以下命令。

```sh
python3 build_ae.py --lang en
python3 build_cep.py --lang en --out dist
```

第二条命令生成 `dist/JIZURA_CEP_en.zip`。提供 GitHub Pages 下载时，将 ZIP 复制到仓库根目录。构建后的页面、面板和翻译源文件应一并提交。

### 11.4 在自己的仓库发布

1. 将包含根目录 `index.html` 的仓库推送到 GitHub。
2. 打开“Settings → Pages”，将 Source 设为“Deploy from a branch”，Branch 选择 `main`，目录选择 `/ (root)`，然后保存。
3. 等待数分钟后，通过 `https://<用户名>.github.io/<仓库名>/` 访问。

英文版和印尼文版分别位于仓库网站的 `/en/`、`/id/` 路径，其他语言使用各自目录。各版本的 HTML 也可在本地打开，离线字体由已安装字体替代。
